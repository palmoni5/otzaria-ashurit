# Otzaria Ashurit

גופן כתב אשורית בשתי משפחות ובשני משקלים, לטור הסת"ם ולטור הניקוד של
תיקון הקוראים באוצריא.

| קובץ | משפחה | תפקיד |
|---|---|---|
| `OtzariaAshurit-Regular.otf` | Otzaria Ashurit | טור הסת"ם |
| `OtzariaAshurit-Bold.otf` | Otzaria Ashurit | " |
| `OtzariaAshuritNikud-Regular.otf` | Otzaria Ashurit Nikud | טור הניקוד |
| `OtzariaAshuritNikud-Bold.otf` | Otzaria Ashurit Nikud | " |

## מה יש בגופן

- 27 אותיות הכתב, עם תגין.
- **נו"ן הפוכה** (U+05C6) — בגופני סת"ם היא חסרה בדרך כלל, והמנוע נאלץ
  לשקף נו"ן רגילה.
- **אותיות מתרחבות** — **ה ל ם ר ת ד** בשש מדרגות רוחב, ליישור הטור בלי
  למתוח את הרווחים שבין המילים. הן יושבות בטווח ה-PUA, החל מ-U+E100,
  שמונה קודים לכל אות: `U+E100 + סדר האות × 8 + מספר המדרגה`, לפי הסדר
  שלמעלה. המתיחה שומרת על עובי הגזעים ובולעת את התוספת במקטעים שביניהם,
  כדרך שסופר מרחיב אות; התג וכל מה שמשמאלו נשארים כגוש קשיח, אחרת נקודת
  התג נמעכת לאליפסה ונודדת מן השפה.
  א' אינה בקבוצה: אין בה גזע אנכי אלא אלכסון, ומתיחה אופקית משטחת אותו.
- **ניקוד וטעמים** — במשפחת Nikud בלבד, **כל** הטווח U+0591–U+05C7 עם
  טבלאות המיקום שלהם; תו אחד שנופל נלקח מגופן אחר ובולט באמצע המילה,
  ולכן `tools/check.py` אוכף כיסוי מלא. במשפחת הסת"ם אין להם מיפוי כלל,
  וזה מכוון: כך החלפת הגופן האוטומטית פועלת כשמגיע תו מנוקד, במקום
  להציג גליף ריק.
  קמץ קטן, חולם חסר לוי"ו ונקודה תחתונה חולקים גליף עם קמץ, חולם וחיריק
  — צורתם זהה — ולכן הם יורשים את מיקומם כלשונו. עתנח הפוך הוא גליף
  משלו: שיקוף אנכי של האתנחתא, המשתתף בדיוק במקומות שהיא משתתפת.

ארבעת הקבצים **תואמים מטרית**: לכל תו אותו רוחב בכל הקבצים, כדי ששני
הטורים יישארו מיושרים זה מול זה והחלפת משקל לא תזיז אף שורה. `tools/check.py`
אוכף זאת בכל בנייה.

גם **המדדים האנכיים זהים** בארבעת הקבצים — `hhea`, `sTypo*` ו-`usWin*` —
כדי ששני הטורים יישארו שורה מול שורה.

ל' ו-ך' חורגות מגובה השורה. תיבת החיתוך (`usWin*`) הורחבה כדי שלא ייחתכו,
אבל ריווח השורות (`hhea`) נשאר קטן ממנה, כדי שהחריגה לא תדחק את השורות.

## בנייה

```bash
pip install -r requirements.txt
python src/build.py out
```

הבנייה דטרמיניסטית: שתי בניות של אותו קומיט מוציאות קובץ זהה בתים. ה-CI
מאמת זאת בכל דחיפה.

```bash
pip install -r requirements-qa.txt
python tools/package.py out               # הרכבת חבילת ה-Flutter
python tools/check.py out                 # בדיקות תקינות וחוזה החבילה
python tools/proof.py out qa              # דפי הוכחה, גליף גליף
python tools/verify.py out reference_dir  # השוואה מול קבצים קודמים
```

## צריכה כחבילת Flutter

התיקייה `package/` היא חבילת Flutter תקינה, וקובצי הגופן מקומטים בה תחת
`lib/` — תלות git מושכת את המאגר עצמו ולא את נכסי הרילייס. האפליקציה
הצורכת מצהירה:

```yaml
dependencies:
  otzaria_ashurit:
    git:
      url: https://github.com/palmoni5/otzaria-ashurit.git
      path: package

flutter:
  fonts:
    - family: Otzaria Ashurit
      fonts:
        - asset: packages/otzaria_ashurit/OtzariaAshurit-Regular.otf
        - asset: packages/otzaria_ashurit/OtzariaAshurit-Bold.otf
          weight: 700
    - family: Otzaria Ashurit Nikud
      fonts:
        - asset: packages/otzaria_ashurit/OtzariaAshuritNikud-Regular.otf
        - asset: packages/otzaria_ashurit/OtzariaAshuritNikud-Bold.otf
          weight: 700
```

**שם החבילה, נתיב ה-`path` ושמות הקבצים הם חוזה** — שינוי בהם שובר את
הבנייה של הצרכן. `tools/check.py` אוכף אותו, ואוכף גם שהקבצים שבחבילה
הם בדיוק הבנייה הנוכחית. `lib/otzaria_ashurit.dart` מחזיק את שמות שתי
המשפחות כקבועים, כדי שלא ייכתבו כמחרוזות חופשיות.

`package/pubspec.yaml` נוצר מ-`tools/package.py` ואין לערכו ביד; גרסתו
נגזרת מ-`VERSION` — `1.002` הופך ל-`1.0.2`.

`test_consumer/` הוא צרכן דמה שמצהיר על הגופנים בדיוק כמו אוצריא, ומודד
כל גליף במנוע עצמו מול מה שהגופן מצהיר ב-hmtx. זו אינה כפילות לבדיקות
שבפייתון: Skia קוראת את רוחב ה-advance מן ה-CFF, וטעות שם אינה נראית
בשום קריאה דרך fontTools. הטבלה `test/expected.g.dart` נוצרת מן הגופן
הבנוי ואין לערכה ביד.

```bash
cd test_consumer && flutter pub get && flutter test
```

## מבנה המאגר

```
sources/    קובצי המקור — UFO לכל משקל, ו-TTX לטבלאות הפריסה
src/        הבנייה: הרכבת UFO לגופן, ומתן השמות והגרסה
tools/      בדיקות, הוכחות והרכבת החבילה
package/    חבילת ה-Flutter — נוצרת מ-tools/package.py ומקומטת לגיט
VERSION     מספר הגרסה. שינויו על main מפרסם רילייס
```

קובצי ה-UFO מחזיקים את **צורתו הסופית של כל גליף**. אין כאן שלב שמשנה
צורת אות בזמן הבנייה, ולכן עריכת צורה נעשית במקור עצמו — בעורך גופנים או
בקוד — ומה שנבנה הוא מה שכתוב.

## גרסה ורילייס

`VERSION` הוא מספר הגרסה היחיד: הוא נכתב לטבלת השמות ול-`head`, וה-CI
בודק שהם תואמים. דחיפה ל-`main` שבה `VERSION` אינו תואם רילייס קיים
מפרסמת רילייס חדש עם ארבעת הקבצים.
